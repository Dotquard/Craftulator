# Craftulator

Craftulator adds a simple calculator directly into Minecraft's vanilla Recipe Book search box.

You can enter mathematical expressions such as:

`13*64+30`

and Craftulator will display:

`= 862`

## Features

- Calculator built directly into the vanilla Recipe Book
- No REI or JEI required
- Supports addition, subtraction, multiplication and division
- Supports parentheses
- Supports decimal numbers
- Normal Minecraft item searches still work normally

## Example

Type:

`13*64+30`

Craftulator calculates the result directly inside the Recipe Book.

## Compatibility

- Minecraft 26.3
- Fabric
- Client-side mod
